萬族境界對照總表

修仙界浩瀚無垠，各族功法體系繁雜。此表以人族「道修」體系為基準，將妖族、魔族、靈界百族（飛靈族、靈族等）的職階與稱號進行橫向對齊，助道友快速釐清實力層級。

人界篇階段 靈界篇階段 仙界篇階段
境界位階 人族 / 道修 妖族 / 海族 魔族 異族 (靈族/飛靈族等) 壽元與修為特徵
第一階 煉氣期 一至三級妖獸 魔卒 / 下位魔族 靈徒 / 異族平民 壽元約百歲。可引氣入體，使用法器與低階法術。
第二階 築基期 四級妖獸 魔騎 靈師 / 低階飛靈 壽元兩百餘歲。真氣液化，可辟穀、御器飛行。
第三階 結丹期 五至七級妖獸 魔將 靈將 壽元五六百歲。丹田結出金丹，可煉製本命法寶。
第四階 元嬰期 八至十級妖獸 (八級可化形) 高階魔族 / 魔君 靈帥 / 飛靈將 壽元千年。碎丹成嬰，元嬰出竅可保命，具備瞬移能力。
第五階 化神期 化神期大妖 魔尊 (初階) 靈尊 / 飛靈帥 / 聖子 壽元兩千至數千歲。可初步調動天地元氣，人界巔峰極限。
第六階 煉虛期 煉虛期大妖 魔尊 (中階) 尊者 / 上族 / 聖族 壽元理論破萬。元嬰化虛與肉身相融，可施展法相金身。
第七階 合體期 合體期大妖 魔尊 (高階) / 聖祖分身 聖階 / 聖靈 / 長老 壽元數萬年。肉身與天地元氣徹底合一，靈界一方霸主。
第八階 大乘期
(含渡劫期)		 大乘期真靈 魔族聖祖 靈王 / 聖祭 / 大族長 壽元十萬年以上。掌握法則皮毛，靈界/魔界法則容納之極限。
第九階 真仙境 真仙級真靈 真靈魔 / 魔仙 飛升仙界，種族界限淡化 壽命無盡(需度天人五衰)。凝練仙竅，轉換仙靈力。
第十階 金仙境 金仙級真靈 - - 掌握實質化的法則之絲，開闢專屬靈域，仙界中堅力量。
第十一階 太乙境
(太乙玉仙)		 太乙大妖 - - 法則化域，靈域具備造物之能，可擔任仙域之主。
第十二階 大羅境 大羅級真靈 - - 斬卻三尸，法則大成。仙界真正的巨頭，輕易不涉世事。
萬界頂點 道祖境 真靈始祖 萬魔之主 - 身融天道本源，一法一界之主。不可言說，言出法隨。

備註 1： 妖族在八級（對應元嬰初期）即可經歷化形雷劫化為人形；十級妖獸則對應元嬰後期大圓滿。

備註 2： 靈界異族（如飛靈族、蜉蝣族、木族等）稱號極多，通常「聖子」為化神至煉虛期天驕，「聖階」泛指合體期長老。

備註 3： 仙界篇由於跨度極大，且百族界限已淡化，大多統一使用「真仙、金仙、太乙、大羅」等仙家境界稱呼。
